# OneOps Product State

## Core
Evidence -> Hypothesis -> Experiment -> Reproduce -> Verify -> Approve -> Recover -> Learn

## Hero incident
Bad Green deployment caused by dependency/configuration regression.

## Phone-first
Camera capture, voice input, local-first triage, incident investigation, approval.

## Execution
Office Kit is the laptop-side execution bridge; phone remains command/approval surface.

## Security side layer
Endpoint-aware rate limiting, blocked request telemetry, basic WAF signals and log-integrity evidence. Secondary only.

## 30-hour rule
One complete reliable workflow is more valuable than broad but broken integrations.

## Testing rule
Deliberately test insufficient evidence, contradictory evidence, wrong hypotheses, failed fixes, regressions, recurrence, camera/model/cloud/Office Kit failures, timeout and idempotency.
